# 落雁 · 项目简介

> 本文档面向开发者、内容编辑和寮管理层，概要介绍「落雁」阴阳寮运维网站的产品定位、核心模块与用户旅程。

---

## 一、产品定位

**落雁** 是一款面向《阴阳师》单个阴阳寮（预留多寮联盟扩展）的一站式运维门户。

| 面向对象 | 核心价值 |
|----------|----------|
| **寮管理层**（会长/副会长/精英） | 公告发布、活动排期、成员活跃度管理的**运维工具台** |
| **寮成员** | 黑话词典、日常清单、PVP/PVE 指导、副本攻略的**知识库** |
| **游客/潜在成员** | 寮形象展示与**招新入口** |

---

## 二、为什么要做落雁

阴阳寮的日常运维高度依赖人工，目前存在以下痛点：

1. **信息分散**：公告在微信群、攻略在 B 站/大神、通知在游戏内，新人找不到北
2. **时间固定但易忘**：麒麟 19:00、道馆定时开，错过就是全寮损失
3. **萌新成本高**：黑话听不懂、御魂不会配、副本打不过，问多了怕烦人
4. **管理工具原始**：花名册靠 Excel、活跃度靠记忆、招新靠贴吧发帖

落雁把「管理工具 + 知识库 + 攻略中心」集中到一个平台，让寮运维**有工具、有标准、有沉淀**。

## 三、核心模块概览

### 3.1 公告中心
- 管理端富文本编辑发公告，支持置顶和定时发布
- 成员端列表 + 详情，移动端优先阅读体验
- 关键公告（活动开启、清人预告）强提醒

### 3.2 黑话词典
- **萌新第一站**：资源货币、副本简称、御魂属性、抽卡运气、玩家文化五大分类
- 首期 ≥ 80 条词条，按拼音首字母 + 分类筛选
- 远期目标：攻略正文中的黑话自动识别并悬停释义

### 3.3 攻略中心（四大频道）

| 频道 | 内容 | 维护频率 |
|------|------|----------|
| **寮运维指南** | 每日/每周/每月 SOP、招新模板、清人预告模板、道馆防守策略 | 按需更新 |
| **PVP 指导** | 斗技段位机制、版本主流体系（如禅吞、挖土、冲浪）、挂机阵容、道馆防守阵容库 | 每版本/每小赛季 |
| **PVE 指导** | 萌新养成路线、黑蛋优先级、每日/每周课表、御魂专题 | 每版本 |
| **副本攻略** | 魂土/魂王、真蛇、秘闻、地鬼、逢魔 4500、超鬼王备战、寮本 | 随版本/活动更新 |

### 3.4 活动日历
- 内置阴阳寮固定活动时刻表（麒麟 19:00、阴界之门周末、狭间暗域等）
- 管理可创建一次性活动（寮宴、合寮战）
- 成员可报名/签到

### 3.5 成员与数据
- **花名册**：游戏 ID、区服、职位、入寮日期、常玩方向、师徒关系
- **活跃度看板**：周功勋统计、清人候选名单、数据导出
- **课表打卡**：日常/周常清单勾选，进度按账号保存

### 3.6 招新页
- 对外展示寮规、福利、招新要求
- 在线申请表单，后台审批后一键回绝/通过
- SEO 优化，可被搜索引擎收录

## 四、用户角色与权限

| 角色 | 可见内容 | 操作权限 |
|------|----------|----------|
| **游客** | 首页、公开攻略、招新页 | 仅浏览 |
| **寮成员** | 全部公开内容 + 花名册、课表打卡、活动报名 | 打卡、报名、评论 |
| **寮管理** | 全部内容 + 管理后台 | 发公告、建活动、录入数据、审批招新、维护攻略 |
| **站长/超管** | 全站 | 用户权限管理、内容审核、数据备份 |

---

## 五、技术亮点

- **全栈 TypeScript**：前后端统一类型，tRPC 端到端类型安全
- **现代化前端**：React 19 + Vite 7 + Tailwind CSS + shadcn/ui，40+ 开箱即用组件
- **和风视觉设计**：靛蓝/朱红/金箔色系，移动端优先
- **结构化内容**：攻略均为后台可编辑的结构化数据，版本更新时快速定位修改
- **预留扩展性**：架构上预留多寮（联盟）扩展、群机器人同步等能力

## 六、迭代节奏

| 阶段 | 周期 | 目标 |
|------|------|------|
| **V1.0 MVP** | 2–3 周 | 首页、公告、黑话词典（≥80 条）、攻略中心（四大频道各 ≥3 篇）、用户权限、后台管理 |
| **V1.1** | +2 周 | 活动日历、花名册、活跃看板、招新申请、全站搜索 |
| **V2.0** | 视运营 | 黑话联动、课表打卡、留言讨论、群机器人同步、多寮扩展 |

## 七、与其他工具的关系

| 工具/平台 | 落雁的定位差异 |
|-----------|---------------|
| **微信群/QQ群** | 落雁做「沉淀」，群做「即时通知」，互补而非替代 |
| **网易大神/TapTap** | 大神是全站攻略，落雁是**寮专属**攻略 + 管理工具 |
| **B站攻略视频** | 落雁做文字/图文版速查，视频做详细讲解，互相引用 |
| **Excel 花名册** | 落雁替代 Excel，支持在线协作、数据看板、导入导出 |

## 八、如何参与

- **攻略组**：熟悉玩法，愿意整理和更新攻略内容
- **开发组**：前后端开发、UI/UX 设计、测试
- **运营组**：内容审核、招新文案、活动策划

> 落雁不是一个人的项目，而是一个寮的「数字基础设施」。
